# Laravel Loadout

Laravel Loadout is a free tool for building, saving, and sharing Laravel starter stacks.

- Product name: Laravel Loadout.
- Tagline: Build, save and share your Laravel starter stack.
- Package manager: Yarn. Prefer `yarn` and `yarn run ...` for frontend commands.
- Local environment: Laravel Sail with MySQL, Redis, and Mailpit via `compose.yaml`.
- Frontend stack: Inertia 3, React 19, TypeScript, Tailwind 4, and shadcn/ui.
- Auth stack: Laravel Fortify through the official Laravel React starter kit.
- Keep the first release focused on selecting stack components, saving authenticated loadouts, and sharing public loadout URLs.
